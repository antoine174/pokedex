# 🧭 Pokédex App

Welcome to my **Pokédex**!  
This is a simple and fun web app I built using **React**, **HTML**, **CSS**, and **Fanta.css**.  
It connects to the [PokéAPI](https://pokeapi.co/) to show real Pokémon with their stats, types, and abilities — all inside a clean and responsive interface.

## ✨ What You Can Do

- 🔍 **Search for any Pokémon** by name or ID  
- 🧠 See **real-time data** straight from the PokéAPI  
- 🖼️ Check out **Pokémon cards** with images, stats, types, and abilities  
- 📱 Enjoy a **fully responsive layout**, so it works on mobile and desktop  
- ⚡ Experience **smooth navigation** thanks to React

## 🛠️ Tools & Technologies

- 🧰 **React.js** – for building the UI  
- 🎨 **HTML & CSS + Fanta.css** – for styling and layout  
- 🌐 **PokéAPI** – for fetching Pokémon data
